# bsteuern/signatur

Assets fuer die E-Mail-Signaturen der Kanzlei.

## Achtung

Die Dateien unter `embleme/` werden per jsDelivr direkt in versendeten
E-Mails verlinkt. Diese Adressen sind unveraenderlich.

**Nicht loeschen. Nicht umbenennen. Nicht auf privat stellen.**

Wer hier etwas entfernt, macht jede jemals versendete Signatur kaputt.
Rueckfragen an Florian.

## Inhalt

- `embleme/` 175 Emblem-Kacheln, 220 x 268 px
- `signatur.css` Stylesheet des Generators
- `signatur.js` Logik des Generators
- `wordmark-*.svg` Wortmarken, aus denen die Embleme entstanden sind

Das Werkzeug liegt auf bsteuern.com/intern/signatur.
